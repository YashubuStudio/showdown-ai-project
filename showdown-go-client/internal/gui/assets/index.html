Local Control Surface

Showdown のローカル対戦ルールと検証導線をまとめて握る操作盤

接続確認だけでなく、ローカル専用フォーマットの編集、対象ポケモンの切り替え、 チーム検証、カスタムチーム付き模擬戦闘までひとつに集約した Go クライアントの GUI。

CLI: showcli
API: /api/local-format /api/validate-team /api/mock-battle
Mode: LAN / local format studio

Connection

まず接続先と識別用の名前を決める。人間でも bot でも、ここを変えれば同じ導線で試せる。

Studio Format

ローカル専用フォーマットの基準、チームサイズ、対象ポケモン、追加禁止ポケモンをまとめて編集する。

保存すると [Gen 9] Showdown Suite Studio が更新される。 ブラウザクライアントと Go 側 API は同じ定義を前提に動く。

Battle Sandbox

同じローカルフォーマットを使ってチーム検証と模擬戦闘を行う。チーム欄を空にすれば従来どおりランダム battle も叩ける。

team_a / team_b を送ると、battle 開始前にローカル validator で format 適合性を確認してから挑戦を投げる。

Usage Notes

`status` は room list と接続状態を見る用。ローカル鯖が静かなときは値が少なくても正常。
`[Gen 9] Showdown Suite Studio` はサーバー側で定義される固定フォーマット。GUI から変えるのはその中身。
対象ポケモンプール外や追加禁止ポケモン入りの構成は validator が明示的なメッセージで弾く。
GUI から叩いているのはローカル API なので、同じ処理を他アプリや CLI からも使い回せる。
